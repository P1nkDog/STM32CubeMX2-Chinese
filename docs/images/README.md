# 截图说明

本目录存放 README「效果预览」章节使用的截图。

## 命名与引用

README 里只引用一张：`![汉化后](docs/images/after.png)`。
换图就是覆盖 `after.png` 这一个文件，不用改图片链接
（只有当截图展示的界面变了，才顺手改「效果预览」那句说明）。

## 该截什么

- **信息量优先**：一屏里同时能看到多个已翻区域的那张最好。当前这张是
  引脚配置（Pinout）视图 —— 顶部菜单、左侧工具栏、右侧详情视图、
  展开的 GPIO 模式下拉、右键菜单全在里面。
- 挑已收录文案密集的界面，别挑还大片英文的界面。
- 尺寸没有硬要求：GitHub 会按容器缩放，宽度 1400–2600 都合适
  （太窄会看不清面板里的下拉选项）。

## 换图步骤

1. 新图先单独看一眼，确认没有本机敏感信息 —— 工程名（`test`）、
   器件型号（`STM32C542RCT6`）可以留；用户名、个人目录、桌面路径要裁掉。
2. 覆盖到 `docs/images/after.png`。
3. 在 README 的渲染视图里确认显示正常，再提交。

老图不用手动备份：`after.png` 是入库文件，
`git log --follow -- docs/images/after.png` 列出历史版本，
`git checkout <commit> -- docs/images/after.png` 取回任意一版。
